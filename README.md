# Byom

Десктопное WPF-приложение, куда пользователь кидает CSV-выписку из банка, а оно категоризирует транзакции, строит графики и находит аномалии.

## Функциональность (MVP)

- Загрузка CSV — drag&drop или кнопка «Выбрать файл»

- Парсинг — асинхронно, со стримингом, показ прогресса

- Категоризация — по ключевым словам в описании (Пятёрочка → Супермаркеты, Яндекс.Такси → Транспорт)

- Сводка — топ категорий, сумма за период, средний чек

- Графики — расходы по месяцам (bar chart), доли категорий (pie chart)

- Таблица транзакций — с фильтром и сортировкой, виртуализированная

## Расширения

- Правила категоризации, редактируемые пользователем (сохраняются в JSON)

- Поиск аномалий («в этом месяце категория X выросла в 3 раза»)

- Экспорт отчёта в Excel (ClosedXML) и PDF

- SQLite для истории импортов

- Тёмная тема

- Сравнение месяцев («этот vs прошлый»)
